# Báo cáo lập kế hoạch chuyển SePay Test sang Live

**Thời điểm:** 29/10/2026 22:24 UTC+7.  
**Mục tiêu:** Khảo sát source và tiến độ, lập kế hoạch cấu hình Live, API MBBank/SePay, migration Supabase và nghiệm thu; giữ demo/VNPAY sandbox.

## Thực hiện

- Đọc plan gốc, báo cáo P4/P5/P7/backup và source `server/src/main.ts`, `app.ts`, SePay config/API v2/workflows/worker, migration draft và checkout.
- Đối chiếu tài liệu chính thức SePay về Test/Live, API v2, HMAC/webhook/retry; Supabase về RLS và backup. Không đăng nhập Dashboard hoặc gọi SePay API trong phiên này.
- Tạo [kế hoạch Live](../../MBBank_SePay_Live_Plan.md); cập nhật nguồn gốc [MBBank_Payment](../../MBBank_Payment.md), thay quyết định tắt provider cũ bằng yêu cầu mới giữ demo/VNPAY sandbox.

## Phát hiện source

| Mục | Trạng thái quan sát |
|---|---|
| SePay environment | `SepayConfig` chỉ nhận `test`; chưa thể cấu hình Live. |
| API v2 | Cố định Sandbox URL/token; chưa có production client. |
| API/worker production | `main.ts` không truyền SePay config; worker chung chưa poll SePay inbox; local worker chỉ dùng local Test. |
| Provider cũ | `createApplication` có `SEPAY_LEGACY_MODE` cấm bật SePay cùng provider cũ; guard production cấm provider thử. Cần thiết kế/test staging coexistence, không mở demo/VNPAY sandbox trên production. |
| Checkout | Checkout hiện điều khiển demo/VNPAY sandbox, chưa gọi SePay API. |
| Database | P7 inventory không thấy collision ba bảng; backup `public`/restore thử có giới hạn ACL/owner và không phải full Supabase backup. Production draft đã có RLS/revoke nhưng chưa apply. |
