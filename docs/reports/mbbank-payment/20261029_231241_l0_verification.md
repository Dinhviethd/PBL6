## Kiểm thử, sự cố và giới hạn

- `git diff --check`: exit 0; cảnh báo LF/CRLF tại `docs/ui/Feature_B9_QRScan.md`. Git cũng cảnh báo không đọc được global ignore; danh sách status chỉ phản ánh cấu hình Git khả dụng.
- `npm run build` và `npm run check:boundaries` ban đầu bị PowerShell execution policy chặn `npm.ps1`; chạy lại bằng `npm.cmd` thành công. Không thay đổi execution policy.
- Không chạy test DB, webhook, thanh toán, quét QR hoặc migration trong phiên này. Các kết quả P4/P5/P7 trong tài liệu là bằng chứng lịch sử theo đúng phạm vi từng report, không phải kiểm thử lại hoặc bằng chứng Live.
- API/data cũ: không thay code, cấu hình chạy, dữ liệu hay Supabase trong phiên; không tuyên bố hồi quy runtime đã đạt dựa trên build.

## Câu hỏi xác minh đã gửi người dùng

1. Staging cô lập cho demo/VNPAY sandbox/SePay Test đã có chưa; nền tảng production là gì?
2. Domain HTTPS production và người chịu trách nhiệm DNS/TLS/webhook?
3. Tên hoặc project ref của Supabase staging/production; role PostgreSQL thực tế của backend?
4. Quyền liên kết MBBank, Dashboard Live, webhook, token API v2 chỉ đọc và người quản lý secret đã sẵn sàng chưa?
5. Người chịu trách nhiệm backup/PITR, restore, duyệt DDL; retention/RPO/RTO đã định nghĩa chưa?
6. Có chấp nhận source hiện tại làm ứng viên rà soát trước khi chốt commit không?

Các câu trả lời đang chờ tại thời điểm lập báo cáo; không yêu cầu hay lưu secret, token, mật khẩu hoặc số tài khoản đầy đủ.
