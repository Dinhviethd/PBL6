# L4 — Apply Supabase và chuẩn bị runtime Live

Ngày thực hiện: 30/10/2026, UTC+7. **Trạng thái: hoàn tất migration Supabase; L4 chưa nghiệm thu toàn bộ vì chưa chạy runtime/API Live.**

## Phạm vi và quyết định

Người dùng yêu cầu thực hiện L4 trên source hiện tại, tham chiếu MBBank_SePay_Live_Plan và MBBank_Payment. Yêu cầu L4 là căn cứ thực hiện migration đã rehearsal ở L2. Không commit source. Chỉ dùng máy hiện tại/ngrok; không yêu cầu domain, staging hoặc triển khai dài hạn. Backup đã được người dùng lưu ngoài hệ thống, không xác minh thêm. Không seed dữ liệu giả hoặc gửi webhook mô phỏng vào Supabase có dữ liệu thật.

Người dùng đã xác nhận secret webhook và token API v2 Live được tạo riêng. Chưa nhận đường dẫn chứa các giá trị đó trong phiên này. Không yêu cầu gửi secret trong hội thoại. Hai câu hỏi đã gửi: vị trí cấu hình Live trên máy; danh tính buyer/admin và đơn được chọn để kiểm thử API có xác thực.

## Thực hiện

- Thêm runner riêng `server/scripts/sepay-live-migrate.cjs`, không đăng ký migration vào runner chung. Preflight mặc định chỉ đọc; apply cần cờ `--apply-reviewed-sepay-only`, preflight cùng target/hash trong một giờ và đúng bốn baseline.
- Kết nối từ cấu hình hiện có đến Supabase bằng CA `server/.local/certs/supabase-ca.crt`, xác minh TLS. Không xuất connection string, credential hoặc dòng nghiệp vụ vào log.
- Pin SHA256 migration L2: `AD0CC5DE900912E8B25C614BCDCF207864F647867011D04CBA9F44DAAFF486D9`. Build lại thành công trước apply.
- Transaction riêng chạy `SepayLiveFoundation1793319300000.up()`, ghi một dòng history trong cùng transaction. Không chạy migration local hoặc baseline lần nữa. Timeout khóa 2 giây, statement 30 giây.
- Kiểm tra trước commit: ba bảng mới, năm index, RLS/owner, 72 tổ hợp quyền (3 bảng × 3 API role × 8 quyền, gồm MAINTAIN); fingerprint schema/dữ liệu/default ACL cũ; giữ nguyên bốn dòng history trước đó.
- **Commit thành công.** Kết nối mới độc lập chạy script read-only xác nhận trạng thái đã lưu, rồi rollback transaction đọc.
- Tạo `server/.local/sepay-live.env` từ template, chỉ khi chưa tồn tại. File được Git ignore, không chứa credential, `SEPAY_ENABLED=false`. Chưa nạp cấu hình, khởi động Live hoặc đổi tunnel.

## Việc còn lại để hoàn tất L4

1. Xác định file cấu hình Live riêng; điền các trường còn trống trong file ignored: account, webhook secret, API v2 token, database target, JWT/QR secret và client URL. Không dùng credential Test.
2. Validate cùng cấu hình cho API/worker; khởi động runtime ở cổng đã chọn. Worker hiện còn chạy tác vụ legacy expiry/wait queue/reminders, cần ghi nhận khi bật trên dữ liệu thật.
3. Chuyển ngrok đến runtime Live đã xác minh; cấu hình webhook Live đúng URL. Hiện chưa dừng bất kỳ process cũ nào hoặc suy đoán process nào là Test.
4. Dùng curl và tài khoản/đơn đã chọn để kiểm tra quyền buyer/admin, tạo/đọc payment, callback cũ; kiểm tra Data API thực tế bằng credential phù hợp qua file local.
5. Ghi nhận bằng chứng webhook/worker/reconcile thực tế theo phạm vi Live; giao dịch chuyển tiền có kiểm soát thuộc L5. Chưa ghi PAID hoặc phát hành vé Live trong phiên này.

Không có yêu cầu xác minh lại backup/PITR, branch hoặc domain dài hạn.
