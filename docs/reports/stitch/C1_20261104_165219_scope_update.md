## Thiết kế, API và tiêu chí rà soát

Trạng thái thiết kế ban đầu/cuối: ĐÃ CÓ, giữ nguyên artifact; HTML/ảnh đã xem ở report trước. Phiên này không gọi lại Stitch, không edit-screen hoặc tạo màn hình mới. Việc bỏ khối và đổi chart là sai lệch triển khai được người dùng yêu cầu; không đổi theme/font và không sửa màn khác.

API mới chỉ là **đề xuất, CHƯA TRIỂN KHAI/CHƯA KIỂM THỬ**. Không gọi HTTP hay mutation trong phiên này; kết quả GET200/401/403 ở report trước không phải kiểm chứng mới. `/admin/stats` vẫn không hỗ trợ lọc ngày; các API đã loại khỏi scope không còn là blocker.

| Tiêu chí | Trạng thái | Nhận xét |
|---|---|---|
| Phạm vi tài liệu | PASS | Chỉ một API mới cho doanh thu ngày; nhóm còn thiếu khác đã loại rõ ràng |
| Contract kế hoạch | PASS | Có quyền/query/response/timezone/tiền/ngày rỗng/validation/chống trùng và test; chưa phải API chạy thật |
| Nội dung/bố cục frontend | NOT_VERIFIED | Chưa triển khai scope mới |
| Design system/ngôn ngữ | NOT_VERIFIED | Không review lại runtime; giữ bằng chứng phiên trước |
| Điều hướng/nghiệp vụ | NOT_VERIFIED | Kế hoạch giữ API cơ bản, chưa kiểm hành vi phiên này |
| Trạng thái UI | NOT_VERIFIED | Chưa kiểm loading/error/empty mới |
| Responsive/accessibility | NOT_VERIFIED | Không chạy browser |
| Nhất quán triển khai | NOT_VERIFIED | Quy định reuse shell/TSX+CSS multi-line; chưa code |

Tiêu chí nghiệm thu sau: endpoint thật ADMIN200/anonymous401/USER-ORGANIZER403, ngày sai400, series đúng UTC+7 và đủ ngày0, mỗi PAID order một lần qua payment chuẩn, tổng bằng sum(series), snapshot/large amount; UI filter/refresh/error/empty/responsive và không còn nhóm đã bỏ. Không yêu cầu CSV/donut/security/refund để nghiệm thu scope mới.
