## 4. API đã xác minh trước tích hợp

Sau backend build, chạy API mới thật bằng `createApplication` và PostgreSQL17 trong container riêng `eventhub-a13-postgres-test`, loopback55433, database `eventhub_a13_test`. API listen cổng ngẫu nhiên; Vite test5183 proxy tới API này. Không dùng DATABASE_URL Supabase để seed hoặc mutation test. Fixture gồm tài khoản/sự kiện/phân công trên database test, không đưa vào sản phẩm. Ảnh fixture SVG được HTTP server local riêng phục vụ, không phải ảnh mẫu trong source sản phẩm.

| API | Bằng chứng thực tế |
|---|---|
| GET `/api/me/checkin-assignments?page=N` | 200, data vẫn mảng; image_url từ cover thật hoặc null; pagination `{page,pageSize:50,total,totalPages}`; count0/1/50/51, trang tiếp/vượt, tie-break invited_at/id, user khác không lộ dữ liệu |
| GET assignments guest/invalid query | Guest401; page=-1/1.5/10001/bad400 |
| POST `/api/me/checkin-invitations/:id/respond` | Boolean true200/ACTIVE, false200/DECLINED; UUID thuộc người khác404, string boolean400, guest401, hết hạn/đã xử lý/sự kiện hết giờ409, UUID thiếu404/sai định dạng400 |
| GET `/api/checkin/events/:id` | Staff pending403, ACTIVE200 đúng event, sau thu hồi403; browser mở đúng route và tải heading scanner |
| POST `/api/checkin/events/:id/checkins` | Test staff hiện hữu kiểm chứng QR/code200, duplicate chỉ1 lần ghi, scan sai event403 và thu hồi ngăn scan tiếp; giữ nguyên source scanner |

Response mẫu theo contract đã kiểm chứng:

```json
{
  "success": true,
  "data": [],
  "pagination": { "page": 0, "pageSize": 50, "total": 0, "totalPages": 0 }
}
```

Items và count lấy bằng cùng SELECT với LEFT JOIN giữ count khi trang rỗng, tránh hai snapshot khác nhau. Quyền lấy principal, không nhận userId từ query. Client metadata ở cấp envelope; mobile/web consumer cũ vẫn đọc data mảng. Đã đọc mobile staff/useResource để đối chiếu, chưa chạy native app.
