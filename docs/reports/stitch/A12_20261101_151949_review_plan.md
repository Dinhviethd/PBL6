| Thử nghiệm | Kết quả thực tế |
|---|---|
| GET `/me/notifications?page=0&unread=false` customer | 200, `{"success":true,"data":{"items":[],"hasNext":false,"unreadCount":0}}` |
| GET cùng route organizer | 200, items0, unreadCount0 |
| GET `?page=0&unread=true` customer | 200, items[], hasNext false, unreadCount0 |
| GET `?page=1&unread=false` customer | 200, items[], hasNext false, unreadCount0 |
| GET `/me/notifications/count` customer | 200, `{"success":true,"data":{"unreadCount":0}}` |
| GET `?page=-1` / `?unread=1` customer | 400 VALIDATION cho cả hai |
| POST `/me/notifications/read-all` customer | 200, `{"success":true,"data":null}`; chỉ gọi sau khi xác nhận unreadCount0; count sau vẫn0 |
| POST `/me/notifications/not-a-uuid/read` customer | 400 VALIDATION, Invalid UUID |
| POST `/me/notifications/00000000-0000-4000-8000-000000000000/read` customer | 404 NOT_FOUND, Không tìm thấy thông báo |
| Guest GET inbox/count, POST read-all/read UUID | 401 cả bốn |

Request POST không body, Bearer khi authenticated. Query page zero-based0..10000; unread đúng chuỗi true/false. Scope user lấy principal, không gửi userId. Contract item/50 items/hasNext/count đã kiểm tra source; chưa có response runtime chứa item để kiểm chứng serialization. Read-all trên hộp thư rỗng chỉ chứng minh route hoạt động trong trường hợp no-op, không chứng minh cập nhật dữ liệu thực.
