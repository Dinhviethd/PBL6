## 5. API đã kiểm tra và giới hạn

**Chỉ xác minh source**, không có môi trường/runtime response, status code hay tích hợp mới được chứng minh trong phiên này:

- `GET /api/organizer/events/:id/orders`: protect + events.guard; page/status/q, page×50; store trả array 50 tối đa, chỉ tìm mã/tên, không có total/pages/join payment/items/tickets. Route chưa truyền from/to dù store có tham số này; chưa có provider/page-size query tương ứng.
- `GET /api/organizer/events/:id/stats`: booking overview → order summary, orders/revenue/sold chỉ cho PAID, không đủ năm KPI.
- `GET /api/organizer/events/:id`, `GET /api/organizer/events`: nguồn event hiện có cần runtime kiểm tra trước tích hợp.
- `GET /api/me/orders/:id`, `/api/me/order-history/:id`: ngữ cảnh buyer, không mặc định thay contract B7 Organizer.
- `POST /api/admin/sepay/reconcile`: source yêu cầu ADMIN; không cho Organizer dùng nút này như chức năng có sẵn.
- Endpoint phù hợp cho export toàn tập, resend, VAT, audit/hoàn tiền B6 chưa được xác minh trong phần source đã đọc.

Không cần gọi API thanh toán hay mutation để lập tài liệu. Chưa tích hợp nên không có tuyên bố API hoạt động; cần kiểm tra HTTP với tài khoản hợp lệ trước phiên triển khai. Nếu không đủ API, dừng phần tích hợp và ghi BLOCKED; không dùng mock/hard-code che thiếu dữ liệu.
