## 4. API đã xác minh trong phiên

Base URL `http://localhost:8000/api`. Route Express → module/workflow theo source thực tế, không giả định controller riêng. Không ghi mật khẩu/token. Chi tiết payload/field mapping đầy đủ tại mục 4–5 của plan.

| Method / route | Request và bằng chứng |
|---|---|
| GET /health | 200, {success:true,data:{status:"ok"}} |
| POST /auth/login | ADMIN seed → 200, có accessToken |
| GET /auth/me | 200, có idUser/name/email/phone/roles/permissions |
| GET /admin/events | status=PENDING_REVIEW&page=0&limit=6 → 200, total 2 |
| GET /organizer/events/a5572651-c50c-443a-a55e-1474e615c852 | 200, TECH CONNECT SUMMIT 2026, PENDING_REVIEW, review_version 1, 1 ticketTypes, reviews rỗng |
| GET /admin/organizers/summaries | ids=44f75b80-80dd-41b0-acdb-d8acf066284c → 200, EventHub Community, contact_name/account_name |
| GET /admin/events/filter-options | 200, 6 categories |
| GET /admin/organizer-applications | status=APPROVED&page=0&limit=50 → 200, total 2; 1 record khớp BTC có email/phone |
| POST /admin/events/:id/review (ID thật) | {approve:false,reason:""} → 400 VALIDATION; {approve:"true",reason:""} → 400 VALIDATION |
| GET /organizer/events/:id không token | 401 UNAUTHORIZED |
| GET detail lại | 200; response bằng response trước các POST validation |
| GET detail UUID không tồn tại | 00000000-0000-4000-8000-000000000000 → 404 NOT_FOUND |
| POST review UUID không tồn tại | Hai payload hợp lệ {approve:true,reason:""} và {approve:false,reason:"C9 verification: missing record"} → 404 NOT_FOUND |

Response mẫu rút gọn từ detail thật:
```json
{
  "success": true,
  "data": {
    "id": "a5572651-c50c-443a-a55e-1474e615c852",
    "status": "PENDING_REVIEW",
    "review_version": 1,
    "submitted_at": "2026-11-04T07:36:51.935Z",
    "ticketTypes": [
      {
        "name": "VIP",
        "price_amount": "100000",
        "capacity": 100,
        "reserved_quantity": 0,
        "sold_quantity": 0
      }
    ],
    "reviews": []
  }
}
```

Source xác nhận approve(boolean), reason trim <=2000; reject cần lý do. Booking review yêu cầu ADMIN, khóa event và chỉ PENDING_REVIEW; lưu review snapshot/audit rồi PUBLISHED hoặc REJECTED trong transaction. APPROVED là review decision, không phải event status. PUBLISHED không bảo đảm đã đến thời điểm bán vé.

**Không tuyên bố mutation thành công:** không approve/reject một sự kiện thật trong phiên; chưa test 403/race/409 hay ghi history thành công trên DB cô lập C9. Báo cáo C11 trước đã có test riêng nhưng không được tính là kết quả chạy lại. Kết quả tích hợp C9: **chưa tích hợp**; API đọc lõi hoạt động, đầy đủ thiết kế vẫn BLOCKED.
