## Thay đổi theo yêu cầu

Phạm vi C8 chỉ còn: KPI; doanh thu/vé/check-in; thông tin BTC; tìm kiếm/lọc đầy đủ; phân trang có tổng. Loại khỏi phạm vi: export, review một/lô, lock/pause/open sale, audit các thao tác này, Socket realtime và analytics action.

## Contract được lập kế hoạch

1. `GET /admin/events`: metadata list + query filter + `pagination.total`; không trả KPI/BTC/metric.
2. `GET /admin/events/kpis`: chỉ KPI theo filter.
3. `GET /admin/events/metrics?eventIds=...`: chỉ tickets/GMV/revenue/check-in theo batch event ID.
4. `GET /admin/organizers/summaries?ids=...`: chỉ thông tin BTC theo batch organizer ID.
5. `GET /admin/events/filter-options`: chỉ nguồn filter category/city/ticket scale.

Tách endpoint như trên để không gộp toàn bộ dữ liệu C8 vào một response. `GET /admin/events` hiện có vẫn được mở rộng contract, chưa sửa code/route trong phiên này. Chưa có API mới nào được tạo hoặc kiểm thử vì đây là thay đổi plan.
