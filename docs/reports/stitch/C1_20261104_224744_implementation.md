## 4. API và bằng chứng kiểm chứng

### API mới

`GET /api/admin/stats/revenue-daily?fromDate=YYYY-MM-DD&toDate=YYYY-MM-DD`

- Quyền ADMIN; thiếu token401, USER/ORGANIZER403.
- Ngày hợp lệ1970–9998, bắt buộc đủ hai query, không nhận query thừa/trùng; khoảng inclusive tối đa366ngày, lỗi400.
- Thống kê toàn hệ thống từ orders PAID; lấy đúng paid_payment_id → payment SUCCEEDED/succeeded_at, theo khoảng UTC nửa mở của ngày Việt Nam. Không dùng created_at hoặc cộng mọi lần payment retry.
- Thiếu/sai giao dịch chuẩn trả409 ANALYTICS_DATA_INCONSISTENT. Tiền chuỗi số nguyên; đủ từng ngày0/tổng bằng sum(series), no-store. Đọc order/payment qua đúng module trong snapshot chung, batch500 với cursor.

Đã kiểm HTTP trên SourceAPI8031/PostgreSQL55471 riêng, gồm **21 checkpoints**. Dữ liệu fixture cố ý có tổng vượt Number.MAX_SAFE_INTEGER và hơn500 đơn; không phải dữ liệu thật.

| UTC+7 đầu/cuối ngày, ngày0, CANCELLED và payment retry | PASS; đúng ba điểm ngày31/10→2/11 |
| Tổng lớn chính xác | `9007199255090991`, không làm tròn |

| Thiếu ngày/ngày sai/đảo/vượt366/query thừa/query trùng | 400 |
| Năm nhuận đủ366ngày | PASS |

Tất cả hoạt động trong quá trình kiểm API/UI. Không bổ sung API cho nhóm đã bỏ.
