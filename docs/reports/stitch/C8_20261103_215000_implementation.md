## Kết quả

C8 đã được nối vào `/admin/events` qua `Admin.tsx`, thêm vào `isAdminConsolePage` để không bị public shell chồng lên, dùng lại `AdminShell` (gồm `AdminSidebar` và `AdminHeader`). Giao diện mới nằm trong `client/src/pages/admin/C8TotalEvent.tsx`, JSX và CSS cùng file. Dùng palette Cosmic Graffiti, bảng cuộn ngang ở khung nhỏ, có loading/error/retry/empty states. Detail/edit chuyển tới `/organizer/events/:id`.

UI chỉ gọi các API GET thuộc scope đã duyệt; không hiển thị/nối export, review, bulk review, lock/pause/resume, realtime hoặc analytics action. Bảng không tự dựng dữ liệu. Search hỗ trợ title/slug/event ID và tên/tổ chức/contact của BTC; bộ lọc status/category/city/date/ticket capacity. Phân trang có total/totalPages.

## API source được triển khai

| Endpoint | Nội dung |
|---|---|
| `GET /admin/events` | Metadata sự kiện + `pagination {page,limit,total,totalPages}`; filter `q,status,categoryId,cityCode,startsFrom,startsTo,ticketScale,page,limit`. Không gộp KPI, BTC hoặc metrics. |
| `GET /admin/events/kpis` | `total`, `selling`, `pending_review`, `paused_or_cancelled` theo cùng bộ lọc, bỏ phân trang. |
| `GET /admin/events/metrics?eventIds=...` | Vé phát hành, số lượng vé inventory đã bán, GMV/doanh thu PAID, check-ins và tỷ lệ check-in cho tối đa 100 event IDs. |
| `GET /admin/organizers/summaries?ids=...` | Tên tổ chức, contact và tên account của BTC trong trang hiện tại. |
| `GET /admin/events/filter-options` | Danh mục, mã tỉnh/thành và các bucket quy mô ticket capacity. |

API đặt sau middleware ADMIN; query/page/batch ID được validate. Các module gọi store thuộc quyền sở hữu event/order/auth riêng, không đưa dữ liệu khác module vào một endpoint list. Ticket scale hiện tính từ tổng capacity của ticket types chưa archive: dưới 1.000, 1.000–3.000, trên 3.000.

## Đối chiếu yêu cầu và giới hạn dữ liệu

| Tiêu chí | Kết quả |
|---|---|
| Tái sử dụng admin header/sidebar | Đạt ở source; browser chưa kiểm |
| KPI | Đạt ở source cho số lượng/trạng thái event theo bộ lọc |
| Revenue/ticket/check-in | Đạt ở source theo event của trang; chỉ số phụ trên đầu trang được ghi rõ là “trang này” |
| BTC | Đạt ở source; endpoint trả summary riêng |
| Tìm kiếm/lọc và pagination total | Đạt ở contract source; chưa chạy trên DB thật/cô lập |
| Detail/edit | Link `/organizer/events/:id` |
| Cosmic Graffiti | Dùng nền `#0f1222/#181b2a`, tím `#7c3aed`, cyan/hồng; giữ mật độ bảng; chưa pixel-diff browser với Stitch |
| Tương thích responsive/a11y | Chưa xác minh bằng browser hoặc công cụ accessibility |

Schema hiện không có mã hợp đồng nên search/display không thể cung cấp trường này. GMV và revenue cùng tính tổng `orders.total_amount` của đơn `PAID`; schema/service hiện không có khoản thanh toán ròng riêng để phân biệt payout. Đếm vé phát hành dựa trên ticket rows không `VOID`; số vé đã bán dùng `ticket_types.sold_quantity`. Tỷ lệ check-in là checkins/vé phát hành. KPI vé/check-in hiển thị trên đầu trang chỉ tổng hợp các dòng của trang đang xem, không đại diện toàn bộ kết quả bộ lọc.
