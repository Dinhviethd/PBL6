## 4. API đã xác minh

| Method/path | Mục đích | Bằng chứng | Kết quả tích hợp |
|---|---|---|---|
| `GET /api/auth/me` | Lấy profile và `createdAt` | `server/src/app.ts`, `GET /auth/me`, `protect` | Đã dùng qua auth store; runtime browser chưa đăng nhập |
| `GET /api/me/tickets` | Lấy danh sách vé để đếm sự kiện đã tham dự | `server/src/app.ts`, `GET /me/tickets`, `protect`, `page` | Đã dùng để tính `tickets.data.length`; browser chưa có phiên |
| `PATCH /api/me` | Lưu tên, số điện thoại, avatar URL sau upload | `server/src/app.ts`, `profileSchema` | Giữ nguyên tích hợp hiện có |
| `POST /api/media` | Upload file avatar field `image`, tối đa 5 MB | `server/src/app.ts`, multer memory storage | Đã dùng trong component upload mới |
| `POST /api/me/password` | Đổi mật khẩu | `server/src/app.ts`, `currentPassword`/`newPassword` | Giữ nguyên tích hợp hiện có |

Các request trong source dùng path không có `/api` vì `client/src/lib/api.ts` đã đặt `baseURL` là `/api`.
