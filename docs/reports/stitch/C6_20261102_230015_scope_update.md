## 4. Bằng chứng API (đã xác minh phiên này)

| # | Kiểm thử | Kết quả thực tế |
|---|---|---|
| 1 | `GET /api/health` | **200** `{"success":true,"data":{"status":"ok"}}` |
| 2 | `POST /api/auth/login` với `admin@example.test` / `LocalDemo2026!` | **200** — `user.roles=["USER","ADMIN"]`, trả `accessToken`, set cookie `refreshToken` |
| 3 | `GET /api/admin/organizer-applications?page=0&limit=5` (Bearer admin) | **200** — `items` đầy đủ trường + `gmv`, `pagination`, `stats {total:4, active:2, pending:1}` |
| 4 | `GET /api/admin/organizer-applications?status=PENDING&limit=3` (Bearer admin) | **200** — chỉ trả hồ sơ `PENDING`; `stats.total` giữ 4 (stats không theo filter), `pagination.total=1` |

Kết quả: **4/4 PASS**. Kết luận: luồng xét duyệt cốt lõi của C6 (danh sách hồ sơ + KPI + lọc + phân trang) dùng API thật, đã hoạt động với dữ liệu thật (4 hồ sơ: 2 APPROVED, 1 PENDING, 1 REJECTED). Chưa gọi `POST .../:id/review` trên Live để không làm thay đổi dữ liệu thật (hợp đồng đã kiểm thử 11/11 ở phiên C4 trên DB tạm).
