## API đã xác minh bằng source và HTTP

Môi trường `http://localhost:8000/api`. Đã đọc method/path/protect/parser trước khi gọi. Page zero-based0..10000; list50/lô, không total/hasNext. POST respond nhận UUID lời mời và boolean accept; GET/POST checkin dùng UUID sự kiện. Envelope như kế hoạch. UUID không tồn tại dùng trong test: `00000000-0000-4000-8000-000000000000`.

| Request/thử nghiệm | Kết quả thực tế |
|---|---|
| GET `/health` | 200, `{"success":true,"data":{"status":"ok"}}` |
| POST `/auth/login`, customer@example.test và organizer@example.test | Cả hai200; token chỉ giữ trong tiến trình |
| GET `/me/checkin-assignments?page=0`, hai tài khoản | 200, `{"success":true,"data":[]}` |
| GET cùng route `page=1`, hai tài khoản | 200, data[] |
| GET cùng route `page=-1`, hai tài khoản | 400 VALIDATION, expected number >=0 |
| POST `/me/checkin-invitations/{UUID}/respond`, `{accept:true}` và `{accept:false}`, hai tài khoản | 404 NOT_FOUND, “Không tìm thấy lời mời.” |
| POST cùng route, `{accept:"true"}`, hai tài khoản | 400 VALIDATION, expected boolean, received string |
| GET `/checkin/events/{UUID}`, hai tài khoản | 404 NOT_FOUND, “Không tìm thấy sự kiện.” |
| POST `/checkin/events/{UUID}/checkins`, `{code:"A13-NONEXISTENT-TEST"}`, hai tài khoản | 404 NOT_FOUND, “Không tìm thấy sự kiện.”; không quét vé có thật |
| Guest GET assignments, POST respond `{accept:true}`, GET checkin event | Cả ba401 UNAUTHORIZED, “Vui lòng đăng nhập.” |

Kết luận truyền dữ liệu: frontend đang truyền đúng query page, UUID lời mời cho respond, boolean accept và UUID event cho scanner theo source; runtime xác nhận parser boolean, page và auth/not-found. **Chưa có lời mời thật trong hai tài khoản**, nên không chứng minh được POST200 chuyển trạng thái hay response list có item. Không đánh dấu các test404 là test thành công nghiệp vụ. Không dùng token tự ký, mock hoặc dữ liệu hard-code thay backend.

Nguồn `staffAssignments` SELECT không có ảnh/category/gate/responded_at, staff_name/staff_email dù client type khai báo hai field cuối; GET checkin detail cũng không phải Assignment đầy đủ. Chưa có API tổng trang/thống kê lời mời toàn bộ. Các test trong `server/test/integration.test.cjs` có luồng staff, nhưng **không chạy lại** trong phiên tài liệu vì có tạo/mutate fixture và cần database test riêng; không dùng kết quả cũ làm bằng chứng mới.
