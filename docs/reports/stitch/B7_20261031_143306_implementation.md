## 4. API đã xác minh trước tích hợp và bằng chứng

Kiểm thử dùng PostgreSQL17 Docker riêng **`eventhub-b7-test`**, image `postgres:17-alpine`, host **127.0.0.1:55437**, DB **eventhub_b7_test**. Test chặn URL không phải local/đuôi `_test`. Migration, fixture users/events/orders/demo payment/check-in chỉ ở DB này. Backend khởi tạo từ `server/dist`, listen cổng loopback động; Chrome/Vite test **http://localhost:5178**, proxy tới backend đó. Không dùng Supabase Live làm fixture hoặc tạo giao dịch tiền thật.

| Method/route (prefix HTTP `/api`) | Bằng chứng hoạt động và kết quả |
|---|---|
| GET `/organizer/events/:id/orders/:orderId` | HTTP200 owner/ADMIN;401 guest;403 buyer/Organizer khác;404 missing/cross-event;400 UUID/query thừa;Cache-Control no-store. Đã tích hợp B7 sau lần API test PASS đầu tiên. |
| GET `/organizer/events/:eventId/orders/:orderId/tickets` | HTTP200 trả PNG QR, giải mã khớp token vé đã phát hành;409 khi review; VOID không QR/không printable. Browser dùng dữ liệu thật, gọi lại trước in; nếu review xuất hiện trước in thì không gọi window.print. |
| GET `/organizer/events/:eventId/order-manager` | Hồi quy B6 API PASS; browser list + filters + 55 đơn/6 trang, API page1 cho trang6; link chi tiết và back giữ trang/filter. |
| GET `/organizer/events/:id`, POST `/auth/login`, GET `/auth/me` | Thực thi qua luồng đăng nhập/tải B6 và deep-link B7 trong browser với API thật. Không ép hết hạn token để nghiệm thu refresh-token riêng. |

Response detail thử: `status=PAID`, `totalAmount="200000"`, `currency=VND`, items2×100000, hai ticket metadata, phone=null, actions.print=true. Không chứa QR token/ciphertext/merchant_account/qrImage. Provider transaction reference có test riêng; attempt FAILED mới hơn không thay payment PAID chuẩn. PENDING_PAYMENT/CANCELLED/EXPIRED vẫn trả metadata200 và không cho QR/in. Check-in thật ở test cho checkedInAt; toàn bộ vé VOID làm actions.print=false.

UI demo năm nhóm không gọi API mutation. Không thêm API invoice, risk/kyc/rotate/audit/POS; không dùng API khách hàng/admin để né ownership Organizer.
