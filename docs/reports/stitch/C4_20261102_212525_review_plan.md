## 6. Bằng chứng API đã xác minh (live)

Môi trường: `http://localhost:8000/api` (container đang chạy), tài khoản seed `admin@example.test`.

| Endpoint | Method | Quyền | Bằng chứng | Kết quả tích hợp (hiện trạng) |
|---|---|---|---|---|
| `/api/admin/organizer-applications` | GET | ADMIN (global `/admin` guard `protect`+`role`) | Không token → `401 UNAUTHORIZED`; có token admin → `200`, envelope `{"success":true,"data":[...]}` | Đã dùng ở tab `applications` (Admin.tsx). |
| `/api/admin/organizer-applications/:id/review` | POST | ADMIN | Source: `decision` = `{approve:boolean, reason:string}` (reason bắt buộc khi từ chối); chưa gọi POST để không thay đổi dữ liệu Live | Đã dùng ở form Phê duyệt/Từ chối. |
| `/api/me/organizer-applications` | GET | USER (đăng nhập) | Không token → `401 UNAUTHORIZED` | Dùng ở A5. |
| `/api/me/organizer-applications` | POST | USER (đăng nhập) | Source: tạo hồ sơ BTC | Dùng ở A5. |

Dữ liệu thực trả về (3 bản ghi hiện tại: 2 `APPROVED`, 1 `REJECTED`). Các field có sẵn: `id, user_id, organization_name, contact_name, contact_email, contact_phone, description, status, reviewed_by, reviewed_at, rejection_reason, created_at, business_name, tax_id_or_business_license, website_or_social, head_office_address, main_event_category, expected_event_scale, logo_url, pending_legal_changes`.
