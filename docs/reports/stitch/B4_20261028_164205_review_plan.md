## API và đánh giá khả thi

| API | Runtime | Kết luận |
|---|---|---|
| `POST /api/auth/login` | 200, nhận access token | Xác thực thành công |
| `GET /api/auth/me` | 200, roles USER/ORGANIZER | Quyền organizer xác nhận |
| `GET /api/categories` | 200, 6 danh mục | Hoạt động |
| `GET /api/organizer/events?limit=10` | 200, 10 sự kiện | Danh sách có quyền hoạt động |
| `GET /api/organizer/events/:id` | 200, một event PENDING_REVIEW; có venue_name/address/city_code/ticketTypes | Đọc event hoạt động, không thấy tọa độ trong response |
| `POST /api/organizer/events`, chỉ title | 400 `VALIDATION` | Body thiếu không được lưu nháp trên server |
| `PATCH /api/organizer/events/:id`, chỉ title | 400 `VALIDATION` | Không hỗ trợ cập nhật một trường; request thất bại, không thay event |
| `POST /api/media` | Không gọi runtime; source multipart `image` giới hạn 5×1024×1024 bytes, Sharp resize tối đa 1600×1600 | Chưa chứng minh upload chạy thật |

Source `eventSchema` yêu cầu toàn bộ thông tin event và check-in cho cả POST/PATCH. `booking.saveEvent` có các guard trạng thái và đơn; event store UPDATE đặt `status='DRAFT'`. Vì thế local autosave có thể được thiết kế cho nháp chưa đủ dữ liệu nhưng không phải server autosave; PATCH đầy đủ sau khi có ID chỉ là khả năng cần kiểm thử, có rủi ro thay đổi trạng thái và không áp dụng mù quáng. Chưa có endpoint nháp từng phần được tìm thấy.

Schema/SQL chỉ lưu tên địa điểm, địa chỉ và city code; không tìm thấy geocoding, chọn/lưu tọa độ. Link tìm kiếm Google Maps theo địa chỉ có sẵn ở trang public là phương án tương lai, không chứng minh bản đồ nhúng/ghim. Chọn ghim cần provider, contract, lưu trữ và xác minh riêng. Không tích hợp API mới trong phiên.
