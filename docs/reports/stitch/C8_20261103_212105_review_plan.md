## API, gaps và kết luận

GET `/admin/events` chỉ có status/page, limit 50, không total. Fields đủ list cơ bản; runtime sample `organizer_id` null. POST review có schema `{approve,reason}` nhưng chưa gọi. Thiếu API KPI/aggregates, search/filter/pagination, DTO BTC/ticket/revenue/check-in, export/bulk/lock/realtime/analytics.

Stitch giữ nguyên. Khi triển khai phải dùng `AdminShell`, tái sử dụng `/organizer/events/:id` cho detail/edit, TSX+CSS cùng tệp và không mock số liệu. Kết quả: **KHÔNG ĐẠT** cho frontend hiện tại. Chưa xác minh browser, responsive, a11y, quyền ADMIN editor hoặc POST trên DB cô lập.
