## Đối chiếu và kết quả

Mã nguồn `POST /api/orders` yêu cầu xác thực, eventId, items và Idempotency-Key; backend kiểm tra bán vé/tồn kho, tính tổng từ giá backend và tạo đơn giữ chỗ. `GET /api/me/orders/:id` cung cấp đơn cho checkout. Chưa thấy route báo giá riêng; kế hoạch ghi rõ tạm tính client chỉ mang tính tham khảo và phương án bổ sung API nếu bắt buộc backend báo giá trước khi tạo đơn. Không có API giảm giá trong phạm vi kế hoạch.

Các API được liệt kê trong kế hoạch gồm GET chi tiết sự kiện, GET auth/me, POST orders, GET chi tiết đơn, POST thanh toán và POST hủy đơn khi cần. Đã kiểm tra sự tồn tại trong mã nguồn, **chưa gọi HTTP, chưa xác minh runtime hay tích hợp**.
