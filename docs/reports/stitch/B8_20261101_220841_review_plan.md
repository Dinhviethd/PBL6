## API đã xác minh

Môi trường: `http://127.0.0.1:8000/api`, Docker `pbl6-api-1`. `GET /health` 200 `{"success":true,"data":{"status":"ok"}}`. `POST /auth/login` demo Organizer thành công; sau đó đăng nhập demo Organizer khác, Customer và Admin để kiểm quyền, không lưu credential vào docs.

| Request | Kết quả đã quan sát |
|---|---|
| GET `/organizer/events?page=0&limit=6` | 200, 6 event, total_results="21"; có metadata qse-grid |
| GET attendees page=0&q= trên 6 event từ picker | 200 cả 6; 5 rỗng, 1 có một vé VALID |
| GET `/organizer/events/cbe172d3-a06a-42fa-8557-abeb50a4044b` | 200, event/ticketTypes/reviews, cửa sổ check-in |
| GET `…/attendees?page=0&q=` | 200, một vé VALID, checked_in_at=null; envelope success/data |
| GET `…/attendees` tìm mã vé/tên/email thật | 200, mỗi query trả đúng một ticket ID gốc |
| GET `…/attendees?page=0&q=B8_NO_MATCH_20261101` | 200, [] |
| GET `…/attendees?page=1` | 200, [] |
| GET `…/attendees?page=-1` | 400 VALIDATION |
| GET attendees với ID not-a-uuid | 400 VALIDATION |

- Backend thiếu filter/tổng trang/KPI đầy đủ, phone/holder/VIP, gate/zone/device, export/import, đổi/thu hồi vé, attendee detail và preview mã không mutation.
