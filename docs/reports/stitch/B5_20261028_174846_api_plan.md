## Kết quả API thật

| API | Kết quả |
|---|---|
| POST `/api/auth/login`; GET `/api/auth/me` | 200; role ORGANIZER |
| GET `/api/categories` | 200; có category test |
| POST `/api/organizer/events` | 200; event thuộc fixture, `DRAFT` |
| GET `/api/organizer/events/:id` | 200; ban đầu `ticketTypes=[]` |
| POST `/api/organizer/events/:id/submit` | 400 `MISSING_TICKETS` khi chưa có loại vé |
| POST `/api/organizer/events/:id/ticket-types` | 200; event ID và giá trả về khớp payload |
| GET `/api/organizer/events/:id` | 200; một loại vé đúng ID, event vẫn `DRAFT` |
| POST `/api/organizer/events/:id/submit` | 200; `PENDING_REVIEW` |
| GET `/api/organizer/events/:id` | 200; `PENDING_REVIEW`, loại vé vẫn hiện |
| POST `/api/organizer/events/:id/ticket-types` sau submit | 409 `EVENT_LOCKED` |

Lần thử đầu luồng cũng đi đến sau submit, nhưng assertion dự đoán 400 cho `EVENT_LOCKED` sai; quan sát thực tế là 409. Đã chạy lại với kỳ vọng đúng và toàn bộ chuỗi trên PASS. Fixture B4 cùng môi trường còn chạy xác thực ownership/validation và media, không thay thế test CRUD đầy đủ. PATCH/DELETE loại vé chỉ xác minh route/source, chưa gọi thử phiên này; các case invalid, REJECTED, mutation cross-owner, race và UI còn phải kiểm thử.
