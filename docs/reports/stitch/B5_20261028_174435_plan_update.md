## API và khả thi

| API / dữ liệu | Bằng chứng source | Kết luận |
|---|---|---|
| GET `/api/organizer/events/:id` | `app.ts` guard event, trả `ticketTypes` qua `orders.types`, kể cả archive | Khả thi làm nguồn bảng; phiên B4 từng xác minh GET 200 trên DB test riêng. Chưa kiểm thử lại phiên này. |
| POST `/api/organizer/events/:id/ticket-types` | `app.ts` + `booking.configureType`; tên, giá, capacity, thời gian, mô tả tùy chọn; event DRAFT/REJECTED | Có route cho thêm; phải kiểm thử runtime CRUD trước tích hợp. GET lại sau thành công để hiện bảng thực. |
| PATCH/DELETE `/api/organizer/events/:id/ticket-types/:typeId` | PATCH toàn bộ cấu hình, DELETE archive, giới hạn trạng thái và sold/reserved; store chỉ cập nhật `archived_at` | Không phải bật/tắt có thể đảo ngược; không có field/trạng thái pause riêng trong schema hiện tại. |
| POST `/api/organizer/events/:id/pause` | body `{paused:boolean}`, workflow/store cập nhật `events.sales_paused`; `order/public.ts` chặn toàn event | Không đáp ứng khóa từng hạng. |
| POST `/api/organizer/events/:id/submit` | workflow yêu cầu DRAFT/REJECTED và loại chưa archive | B4 test trước xác minh không vé trả 400 `MISSING_TICKETS`; chưa chạy lại. |

`GET http://127.0.0.1:8000/api/health` phiên này trả HTTP 200 `{"success":true,"data":{"status":"ok"}}`; health không chứng minh CRUD/toggle hoạt động hoặc Docker đã chạy source mới. Không gọi API mutation hoặc xác thực trong phiên này; chưa tích hợp B5. `docs/database/mvp-schema.sql` giới hạn giá ≤ 900719925474099 trong khi regex API cho tối đa 15 chữ số; DB đang chạy/migration cần đối chiếu runtime trước áp dụng giới hạn.

Khóa/bật lại từng hạng **chưa khả thi bằng API hiện tại**. Kế hoạch tương lai yêu cầu thiết kế cờ riêng, migration/API, guard mua/giữ, xử lý cạnh tranh, hàng chờ và đơn đang tồn tại; quyền, trạng thái event và chính sách đơn phải được xác nhận. Không xem archive hay pause toàn event như giải pháp thay thế. Chưa có API mới, chưa chứng minh hành vi hoạt động.
