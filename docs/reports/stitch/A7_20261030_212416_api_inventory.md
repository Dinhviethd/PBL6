## Danh sách API được ghi vào kế hoạch

| Method / endpoint | Vai trò | Xác minh |
|---|---|---|
| `GET /api/me/order-history/:id` | API chính đề xuất cho A7: nạp lại order/payment/ticket summary và xác thực `PAID` | Route, quyền ownership và mapping đã đọc trong source; runtime chưa gọi |
| `GET /api/me/orders/:id` | Checkout hiện dùng để đọc order và trạng thái trước khi điều hướng | Route/call source đã xác minh; runtime chưa gọi |
| `GET /api/me/tickets` | A8 dùng để hiển thị vé khi CTA điều hướng `/tickets` | Route source đã xác minh; runtime chưa gọi |
| `GET /api/me/tickets/:id` | Chỉ cần nếu A7 liên kết chi tiết vé/QR bằng ID thật | Route source đã xác minh; ID liên quan order chưa được xác minh |
| `POST /api/orders/:id/payments` | Checkout tạo payment VNPay/demo | Route/call source đã xác minh; không gọi trong A7 |
| `POST /api/sepay/orders/:orderId/payment` | Checkout tạo hướng dẫn SePay | Route/call source đã xác minh; không gọi trong A7 |
| `GET /api/sepay/orders/:orderId/payment` | Checkout polling SePay và đọc `orderStatus` | Route/call source đã xác minh; không gọi trong A7 |
| `POST /api/payments/:id/demo` | Kết quả mô phỏng ở chế độ demo local | Route/call source đã xác minh; không gọi trong A7 |
| `POST /api/payments/sepay/webhook` | Backend nhận webhook SePay | Route/workflow source đã xác minh; A7 không gọi |
| `GET /api/payments/vnpay/return` | Backend xử lý VNPay return | Route source đã xác minh; A7 không gọi |

Các endpoint có tiền tố `/api` do router được mount tại `/api`. Không có bằng chứng cho endpoint invoice/PDF nên kế hoạch không đề xuất endpoint đó. API tối thiểu trực tiếp cho A7 là `GET /api/me/order-history/:id`; chỉ dùng ticket detail nếu UI có ticket ID thật. Tất cả trạng thái runtime/response vẫn chưa được xác minh.
