## Đối chiếu code/API hiện tại

- Frontend hiện có route `/checkout/:id`; `Checkout` tải `GET /me/orders/:id`, xác định `isPaid` bằng `o.status === "PAID"`, nhưng vẫn ở trang checkout và hiển thị alert dẫn người dùng tới “Vé của tôi”. Route A7 chưa được xác minh trong App router.
- Checkout có polling: VNPay pending reload order mỗi 3 giây tối đa 60 giây; SePay pending gọi `GET /sepay/orders/:orderId/payment` mỗi 8 giây và reload order nếu `orderStatus === "PAID"`. Đây là bằng chứng source, không phải kiểm thử runtime.
- Backend source khai báo `GET /me/orders/:id`, `GET /me/order-history/:id`, `GET /me/tickets`, `GET /me/tickets/:id`, `POST /orders/:id/payments`, demo payment và SePay payment/webhook. Các API người dùng bảo vệ bằng auth.
- Response/runtime thực tế, liên kết vé với order, invoice/PDF API và payment callback end-to-end chưa xác minh trong phiên. Không gọi API runtime.
