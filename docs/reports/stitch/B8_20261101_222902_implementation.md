## API contract và bằng chứng hoạt động

Môi trường kiểm chứng: PostgreSQL17-alpine container **eventhub-b8-test**, bind127.0.0.1:55448, DB **eventhub_b8_test**; API source **127.0.0.1:8018**, Vite **127.0.0.1:5188** proxy tới8018. Không dùng Supabase/DB Live. Không rollout container pbl6-api-1/pbl6-worker-1.

GET `/api/organizer/events/:id/attendees?paginated=true&page=0&limit=5&q=&status=VALID&ticketTypeId=<uuid>`: status/type tùy chọn, không gửi khi Tất cả. page0..10000, limit1..50 (default5), q.trim max200. status chỉ VALID/CHECKED_IN; UUID type sai/event khác/query lạ trả400. Không có flag paginated giữ legacy data mảng50, page0-based. Response mới `{success:true,data:[...],pagination:{page,pageSize,total,totalPages}}`.

COUNT và SELECT chạy trong db.snapshot REPEATABLE READ, cùng event/q/status/type, tổng vẫn có khi trang rỗng. Query order module chỉ đọc tables thuộc order, validation event qua public interface; boundaries/ownership PASS. ticketTypes lấy GET event hiện có, đã kiểm có loại archived còn vé. Cache-Control no-store.

| Kiểm chứng HTTP thật | Kết quả |
|---|---|
| Fixture63 vé, pageSize5 | total63/totalPages13; 12 trang5 và trang13 có3; không trùng/thiếu ID qua13trang |
| VALID / CHECKED_IN | total40 /20, lần lượt8/4trang; VOID3 chỉ nằm ở Tất cả |
| TypeA / TypeB trùng tên nhưng ID khác | total30 /33; typeA archived vẫn có option và lọc được |
| VALID+typeA / CHECKED_IN+typeB | total7/2trang và0/0trang |
| q mã thật / literal `%`, `_`, backslash / email / q+status+type | 1 vé /10 vé literal /10 /10; q trim đúng |
| q không khớp, event trống, trang vượt100 | [] và metadata tổng đúng, totalPages0 khi rỗng |
| page âm/lẻ, limit0/51, statuslạ/VOID, type invalid/trái event, q201, gateId, paginated=false | 400 |
| Guest / Organizer khác / Customer / Admin | 401 /403 /403 /200 |
| ID không UUID / UUID thiếu event | 400 /404 |
| Legacy không flag | page0 có50, page1 có13; không có pagination, shape mảng giữ nguyên |
