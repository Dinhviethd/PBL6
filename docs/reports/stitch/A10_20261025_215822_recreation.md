## 4. API đã xác minh

| Method/path | Mục đích | Contract đã thấy | Kết quả |
|---|---|---|---|
| `GET /api/auth/me` | Profile và `createdAt` | `GET /auth/me`, `protect`, `auth.profile()` | Route tồn tại; browser chưa đăng nhập nên chưa có response thành công |
| `GET /api/me/tickets` | Danh sách vé | `GET /me/tickets`, `protect`, `page` | Route tồn tại; chưa có phiên để gọi thành công |
| `PATCH /api/me` | Cập nhật profile | `PATCH /me`, `profileSchema` | Route tồn tại; chưa gửi mutation |
| `POST /api/media` | Upload ảnh | `POST /media`, field `image`, tối đa 5 MB | Route tồn tại; chưa upload runtime |
| `POST /api/me/password` | Đổi mật khẩu | `POST /me/password`, `currentPassword`, `newPassword` | Route tồn tại; chưa gửi mutation |

Frontend `client/src/lib/api.ts` dùng base URL `/api`, vì vậy source gọi `/auth/me`, `/me/tickets`, `/me`, `/media`, `/me/password` là đúng hợp đồng.
