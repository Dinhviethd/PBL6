## Thay đổi thực hiện

1. Đặt `SEPAY_ACCEPT_NEW_PAYMENTS=true` trong `server/.env` (Git ignored); chỉ ghi giá trị của cờ này, không đọc/in các credential khác. Runtime Live mặc định trước đây là cho phép nếu cờ bị thiếu, nay cấu hình được ghi rõ.
2. Mở rộng allowlist origin có kiểm tra chặt: giữ `SEPAY_RUNTIME_CLIENT_URL` hiện tại làm origin chính cho email/webhook/runtime; thêm duy nhất origin loopback `http://localhost:5173` cho Vite local, dùng chung cho CORS và bảo vệ refresh-token. Không đưa secret hay thêm domain công khai mới.
3. Đặt `SEPAY_RUNTIME_CLIENT_EXTRA_ORIGINS=http://localhost:5173` trong cấu hình Compose Live.
4. Cấu hình `client/.env.local` (Git ignored) để Vite proxy `/api` và `/uploads` về `http://127.0.0.1:8011` thay vì cổng 8000 không chạy.
5. Build và cập nhật riêng API Live bằng `docker compose -f compose.sepay-live.yaml up -d --build api`. API hiện phục vụ cả frontend production bundle mới tại origin ngrok hiện hữu. Worker Live đang chạy được giữ nguyên, không restart.
6. Thêm kiểm tra hợp lệ cho extra client origins: chỉ cho phép HTTP loopback origins chuẩn hóa; kiểm thử từ chối domain ngoài, HTTPS ngoài localhost và URL có path.
