## 4. API, vấn đề còn tồn tại và giới hạn

API đọc đã xác minh: GET `/api/admin/payments`, GET `/api/admin/sepay/transactions`, GET `/api/admin/sepay/transactions/:id`, GET `/api/admin/stats`, GET `/api/admin/stats/revenue-daily` đều200 có token. Hợp đồng/input/bằng chứng/count và negative tests tại mục3 kế hoạch; không dùng credential hay PII làm evidence.

Mutation SePay chỉ xác minh source: reconcile lookbackMinutes5..1440; reprocess body{} trạng thái ERROR/REVIEW; resolve outcome/reason/evidenceReference. Chưa chạy thành công vì có tác động DB/provider, cần môi trường fixture riêng. `refund_external` là ghi nhận xử lý ngoài hệ thống, không phải API hoàn tiền.

Thiếu: ledger join + total, search đa thực thể, escrow/fees/payout/refund/fraud và counts, chart payout/cơ cấu cổng, chứng từ VAT/Excel/sao kê/ủy nhiệm chi, điều khiển lịch24/7, nguồn cấu hình/support/telemetry/chứng nhận. Không tự tạo API route giả hoặc hard-code số liệu. Tổng SUCCEEDED/provider_received không đồng nghĩa GMV canonical, không suy ra escrow từ tỷ lệ5%.

Đã giải quyết trong phiên: định danh C10, quyền tải artifact qua tool phù hợp, xác minh route đọc và quyền, kế hoạch triển khai cùng danh sách blocker. Chưa sửa bất kỳ lỗi sản phẩm nào.

Chưa xác minh: runtime UI C10 hiện tại, mobile/a11y/pixel diff; mutation thật; lịch sử SePay nonempty; pagination trên50; provider tiền thật; performance, rollout và build/lint (không có code thay đổi nên không chạy). HTTP200 và số bản ghi là snapshot, không phải audit toàn bộ DB hoặc bảo đảm đúng mọi biên ngày.
