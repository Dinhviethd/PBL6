| Method | Đường dẫn | Xác minh | Kết quả |
|---|---|---|---|
| GET | `/categories` | Đối chiếu code | Tồn tại; `SELECT * FROM categories WHERE archived_at IS NULL ORDER BY name`. |
| POST | `/admin/categories` | Đối chiếu code | Tồn tại; `categorySchema` yêu cầu `name` + `slug`. |
| PATCH | `/admin/categories/:id` | Đối chiếu code | Tồn tại; cùng schema. |
| DELETE | `/admin/categories/:id` | Đối chiếu code | Tồn tại; soft-delete (`archived_at`). |
