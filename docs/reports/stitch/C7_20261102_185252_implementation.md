## 7. API đã xác minh

Môi trường: API local `127.0.0.1:8001`, PostgreSQL cô lập `eventhub_test`; xác thực bằng tài khoản ADMIN seed cho môi trường test. Không gọi API production/Live.

| Method | Đường dẫn | Dữ liệu gửi | Kết quả xác minh |
|---|---|---|---|
| POST | `/api/admin/categories` | `{ name: "Âm nhạc <suffix>", description }` không có slug | 200; slug `am-nhac-<suffix>`; `description` lưu đúng |
| POST | `/api/admin/categories` | trùng tên trên | 200; slug `am-nhac-<suffix>-2` |
| PATCH | `/api/admin/categories/:id` | đổi tên + description, không gửi slug | 200; slug giữ nguyên; description cập nhật |
| GET | `/api/admin/categories?q=<suffix>&archived=false&page=0&limit=10` | — | 200; có `event_count=0`, `pagination.total ≥ 1`, `stats.total`/`stats.total_events` là số |
| GET | `/api/admin/categories?q=Integration&archived=false&limit=50` | — | 200; danh mục gắn sự kiện fixture có `event_count=1` |
| GET | `/api/admin/categories?page=0&limit=1` | — | 200; 1 dòng, `pagination.totalPages ≥ 1` |
| DELETE | `/api/admin/categories/:id` | — | 200 (soft-delete); `archived=true` trả `archived_at` |

Bằng chứng: test `admin categories auto-generate slug, expose event_count/stats and keep slug on rename` nằm trong `server/test/integration.test.cjs`; toàn bộ suite chạy `16/16 pass` (2026-11-02).
