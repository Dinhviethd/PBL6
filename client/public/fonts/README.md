# Be Vietnam Pro

Self-hosted normal weights 400, 500, 600, 700 and 800, downloaded on 2026-10-21 from Google Fonts (fonts.gstatic.com, family version v12). The full fonts include Vietnamese glyphs.

Source CSS: https://fonts.googleapis.com/css2?family=Be+Vietnam+Pro:wght@400;500;600;700;800&display=swap

License: SIL Open Font License 1.1, included in `OFL.txt` from https://github.com/google/fonts/tree/main/ofl/bevietnampro.

Declared in `src/index.css` with `font-display: swap`. The browser loads these assets from the application's own origin; no runtime request to Google Fonts is needed.
